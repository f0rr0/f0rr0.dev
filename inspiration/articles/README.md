# Inspiration Articles

Reference material for fast, accessible portfolio interactions that can be built
with HTML, CSS, React, and Next.js.

## Direction

- Prefer semantic content, strong typography, and responsive layout over heavy
  visual runtimes.
- Use CSS transitions, scroll-driven layout, and progressive enhancement for
  motion.
- Keep imagery inspectable and optimized through Next.js image handling.
- Avoid heavy visual runtimes in this project.

# f0rr0.dev

Sid Jain's portfolio, blog, and GitHub commit timeline. Built with Next.js and
deployed on Vercel.

## Local development

Use Node 24 and Bun:

```sh
bun install --frozen-lockfile
bun run dev
```

Open [localhost:3000](http://localhost:3000) to view the site.

The site runs without secrets; the commit timeline requires additional setup.
